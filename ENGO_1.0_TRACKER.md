**`pipeline/power_path.py` built** — 8 general principles (P1-P8, full text in the module docstring): scope resolution to the TILE/REGION an element was found in first (same id/label recurs in different real sub-circuits on one sheet — 'Re','63A','Q1' each appeared 2-3x in unrelated places on the shore-power sheet); token-BOUNDARY matching only, never substring (naive substring gave dozens of false hits — e.g. id 'N' substring-matching inside "GND"; token-boundary matching on the same real sheet did not); multi-hop connections are normal, not ambiguous (a wire's text often names both its neighbors); anchor at an already-resolved equipment fact and walk outward; tag rail (positive/negative/ground/signal/control) from keywords; never fabricate a link — an unmatched reference is kept verbatim as `unresolved`, never guessed. Caught and fixed one real duplicate-detection artifact during validation: overlapping coverage-guarantee grid tiles occasionally re-detect the same physical part twice with a slightly different label (e.g. two 'Q1' entries) — same-id matches are excluded from edge-building (indistinguishable either way), and the earlier self-loop this produced is gone; the duplicate reference now correctly falls into `unresolved` instead.
